# Parity checklist: UI surfaces

*Source: independent read of Blue Grid v0.87 (read-only). Every user-facing dialog, panel, menu and control group in Blue Grid's component folders.*

Decision key: **KEEP** carry over; **REDESIGN** keep the purpose, change the design; **MERGE** fold into the named target; **DROP** do not carry over; **LATER** keep, in the named phase.

The **Owner** column is for you: put ✓ to accept the proposed decision, ✗ to reject it, or a note.
Items marked *unverified* were not confirmed by running or fully reading the code.
